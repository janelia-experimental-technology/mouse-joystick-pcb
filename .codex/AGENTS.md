# Codex Guidance Shim

Before making changes, read `.agents/AGENTS.md` and follow it as the canonical
project guidance for this repository.

If `.agents/handoff.local.md` exists, read it for current local context before
planning or editing.

If `.agents/PLANS.md` exists and the task is multi-step, risky, or likely to
span more than one session, use that file as the living plan and keep it
updated as work progresses.
